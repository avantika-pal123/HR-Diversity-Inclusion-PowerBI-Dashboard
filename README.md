# HR-Diversity-Inclusion-PowerBI-Dashboard
An interactive Power BI dashboard that analyzes workforce diversity, inclusion, and employee demographics. The dashboard provides HR teams with valuable insights into gender representation, hiring trends, promotions, performance, employee distribution, and diversity metrics to support data-driven decision-making and build an inclusive workplace.

HR Diversity & Inclusion Dashboard (Power BI)
📌 Project Overview

The HR Diversity & Inclusion Dashboard is an interactive Power BI project designed to analyze workforce diversity and employee demographics. It helps HR professionals understand representation across different departments, monitor hiring and promotion trends, and identify opportunities to improve workplace diversity and inclusion.

This dashboard transforms raw HR data into meaningful visual insights that support strategic HR planning and diversity initiatives.

🎯 Project Objectives
- Analyze workforce diversity across departments.
- Monitor gender representation.
- Track hiring and promotion trends.
- Evaluate employee demographics.
- Identify diversity gaps.
- Support data-driven HR decisions.
